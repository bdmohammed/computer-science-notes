## 🏗️ Constructors in JavaScript

> In Java, a constructor is a special method with no return type.  
> In **JavaScript**, the `constructor` is a **special method** inside a class that initializes the instance. Unlike Java, JS classes are syntactic sugar over prototypes, but the `constructor` behaves similarly regarding initialization order.

<Aside type="tip">
**🧠 Mental Model**:  
The `constructor` is just a function that runs when you call `new MyClass()`.  
Its job: Set up `this` (the new object) and return it.  
⚠️ **Key Difference**: In JS, if you don't define a `constructor`, one is provided implicitly. If you extend a class, you **MUST** call `super()` before using `this`.
</Aside>

---

## 📋 Constructor Rules in JS

| Rule | Detail |
|------|--------|
| **Name** | Must be exactly `constructor` |
| **Return Type** | Can return an object (overrides `this`) or primitive (ignored) |
| **Quantity** | Only **ONE** constructor per class (No overloading!) |
| **Inheritance** | Not inherited. Subclasses must define their own or use default. |
| **`super()`** | Mandatory in subclasses before accessing `this`. |
| **Static** | ❌ Cannot be static. |
| **Arrow Function** | ❌ Cannot be an arrow function. |

<Aside type="caution">
**🚨 No Constructor Overloading**:  
Java allows `MyClass(int x)` and `MyClass(String s)`.  
JS **does not**. You can only have **one** `constructor()` method.  
✅ **Fix**: Use default parameters or factory methods.
</Aside>

## 🔬 Types of Constructors

### 1. Default Constructor
If you don't write a constructor, JS provides one.

```js
class Service {
    // Implicitly:
    // constructor() {}
}
```

### 2. Parameterized Constructor
Accepts arguments to initialize state.

```js
class Server {
    constructor(port) {
        this.port = port;
    }
}
```

### 3. Subclass Constructor
Must call `super()`.

```js
class ApiServer extends Server {
    constructor(port, apiKey) {
        super(port); // Initializes Parent
        this.apiKey = apiKey;
    }
}
```

## 🔀 Constructor Chaining — `super()` and `this`

In Java, you use `this()` to chain constructors. In JS, you **cannot** call `this()` inside a constructor.  
Instead, you handle logic via **helper methods** or **default parameters**.

### The `super()` Rule

> In a subclass, you **MUST** call `super()` before accessing `this`.

<Code lang="js" title="Correct Inheritance Flow" code={`
class Animal {
    constructor(name) {
        this.name = name;
    }
}

class Dog extends Animal {
    constructor(name, breed) {
        // ❌ console.log(this); // ReferenceError!
        
        super(name); // ✅ Initializes Parent
        
        // ✅ Now 'this' is available
        this.breed = breed;
    }
}
`} />

<Aside type="danger">
**🚨 Production Bug**: Forgetting `super()` in a subclass throws a `ReferenceError`.  
Also, calling `super()` twice is a syntax error.
</Aside>

## 🔒 Private Constructors? (Singleton Pattern)

JS doesn't have `private` constructors in the Java sense. However, we can simulate Singletons or prevent direct instantiation using **Factory Methods** or **Module Scope**.

<Code lang="js" title="Singleton Pattern in JS" code={`
class ConfigManager {
    static #instance = null; // Private static field

    constructor() {
        if (ConfigManager.#instance) {
            throw new Error("Use getInstance() instead");
        }
        ConfigManager.#instance = this;
        this.config = {};
    }

    static getInstance() {
        if (!ConfigManager.#instance) {
            ConfigManager.#instance = new ConfigManager();
        }
        return ConfigManager.#instance;
    }
}

// Usage:
const cfg = ConfigManager.getInstance();
// const bad = new ConfigManager(); // Throws Error if called twice
`} />

## 🔩 Internals — How JS Engines Handle It

1.  **Allocation**: `new` creates a blank object.
2.  **Prototype Link**: Sets `obj.__proto__` to `Class.prototype`.
3.  **Binding**: Binds `this` to the new object.
4.  **Execution**: Runs `constructor()` code.
5.  **Return**: Returns `this` (unless constructor returns a different object).

```js

    // return this;
```

## 🔰 What Is a Constructor?

A constructor = **a special function that initializes a new object when called with `new`**. It sets up the object's initial state, assigns properties, and establishes the prototype chain.

```js
// Function constructor (ES5):
function User(name, email) {
  this.name  = name;   // set up state
  this.email = email;
}

// Class constructor (ES6+):
class User {
  constructor(name, email) {
    this.name  = name;
    this.email = email;
  }
}

const user = new User("Ali", "ali@example.com");
// new → allocates object → runs constructor → returns object
```

## ⚙️ Deep Dive — What `new` Does in V8

```
┌──────────────────────────────────────────────────────────┐
│              new Constructor(args) — INTERNALS           │
│                                                          │
│  Step 1: ALLOCATE                                        │
│  → Create empty JSObject on young-gen heap               │
│  → Assign initial hidden class (empty shape)             │
│                                                          │
│  Step 2: SET PROTOTYPE                                    │
│  → obj.[[Prototype]] = Constructor.prototype             │
│                                                          │
│  Step 3: RUN CONSTRUCTOR                                 │
│  → Call Constructor with 'this' = new object             │
│  → Each this.x = y → property write → shape transition  │
│                                                          │
│  Step 4: RETURN                                          │
│  → Constructor returns an object?  → use THAT object    │
│  → Returns primitive / undefined?  → use 'this'         │
│                                                          │
│  For derived class (extends):                            │
│  → 'this' UNINITIALIZED until super() called             │
│  → super() triggers parent's Steps 1-4                  │
│  → child fields run AFTER super() returns                │
│  → child constructor body continues                      │
└──────────────────────────────────────────────────────────┘
```

### Manual `new` Implementation

```js
function manualNew(Constructor, ...args) {
  // Step 1 + 2: allocate + set prototype
  const obj = Object.create(Constructor.prototype);

  // Step 3: run constructor
  const result = Constructor.apply(obj, args);

  // Step 4: return logic
  return (result !== null && typeof result === "object")
    ? result
    : obj;
}

class Point {
  constructor(x, y) { this.x = x; this.y = y; }
  distanceTo(other) {
    return Math.sqrt((this.x - other.x) ** 2 + (this.y - other.y) ** 2);
  }
}

const p1 = new Point(0, 0);
const p2 = manualNew(Point, 3, 4);

p1.distanceTo(p2);              // 5 ✅
p2 instanceof Point;            // true ✅
Object.getPrototypeOf(p2) === Point.prototype; // true ✅
```

## 1️⃣ Function Constructor — ES5 Style

### Basic Pattern

```js
// Convention: PascalCase signals "must call with new":
function Animal(name, species) {
  // 'this' = newly allocated object:
  this.name    = name;
  this.species = species;
  this.alive   = true;
}

// Methods on prototype — shared across all instances:
Animal.prototype.eat   = function() { return `${this.name} is eating`; };
Animal.prototype.sleep = function() { return `${this.name} is sleeping`; };
Animal.prototype.toString = function() {
  return `${this.species}("${this.name}")`;
};

const lion = new Animal("Simba", "Panthera leo");
lion.eat();    // "Simba is eating" ✅
lion.sleep();  // "Simba is sleeping" ✅
String(lion);  // "Panthera leo("Simba")" ✅

// Verify prototype chain:
Object.getPrototypeOf(lion) === Animal.prototype; // true
lion instanceof Animal;                           // true
lion.constructor === Animal;                      // true
```

### Forgetting `new` — Silent Disaster

```js
"use strict";

function User(name) {
  this.name = name;
}

// Called without new in STRICT mode:
const user = User("Ali"); // ❌ TypeError: Cannot set properties of undefined
// 'this' = undefined in strict mode

// Called without new in SLOPPY mode:
// 'this' = global object → pollutes window/global 😱
const user = User("Ali");
// user = undefined (no return)
// global.name = "Ali" 😱

// Fix 1 — strict mode (always use it)
// Fix 2 — guard in constructor:
function SafeUser(name) {
  if (!(this instanceof SafeUser)) {
    return new SafeUser(name); // force new
  }
  this.name = name;
}

SafeUser("Ali");           // ✅ still works — auto-corrects
new SafeUser("Ali");       // ✅ normal path

// Fix 3 — use class (syntax error without new)
class StrictUser {
  constructor(name) { this.name = name; }
}
StrictUser("Ali");         // ❌ TypeError — class enforces new ✅
```

### Constructor Property — The Fragile Reference

```js
function Dog(name) { this.name = name; }

// Initially:
Dog.prototype.constructor === Dog; // true ✅

// Replacing prototype loses constructor:
Dog.prototype = {
  bark() { return `${this.name}: Woof!`; }
};

Dog.prototype.constructor === Dog;    // false 😱 → Object
new Dog("Rex").constructor === Dog;   // false 😱

// Always restore constructor when replacing prototype:
Dog.prototype = {
  constructor: Dog,                   // ← restore ✅
  bark() { return `${this.name}: Woof!`; }
};

Dog.prototype.constructor === Dog;    // true ✅
new Dog("Rex").constructor === Dog;   // true ✅
```

## 2️⃣ Class Constructor — ES6+

### Basic Class Constructor

```js
class Vehicle {
  // Instance fields — initialized BEFORE constructor body:
  type    = "vehicle";   // ①
  active  = true;        // ②

  constructor(make, model, year) {
    // ③ Constructor body — fields already set:
    this.make  = make;
    this.model = model;
    this.year  = year;
  }

  toString() {
    return `${this.year} ${this.make} ${this.model}`;
  }

  get age() { return new Date().getFullYear() - this.year; }
}

const car = new Vehicle("Toyota", "Camry", 2020);
car.type;     // "vehicle" ✅ — from field
car.active;   // true ✅
car.make;     // "Toyota" ✅ — from constructor
String(car);  // "2020 Toyota Camry"
```

### Implicit Constructor

```js
// No constructor declared — engine provides default:
class Point {
  x = 0;
  y = 0;
  // Implicit for base class:
  // constructor() {}

  distanceTo(other) {
    return Math.sqrt((this.x - other.x)**2 + (this.y-other.y)**2);
  }
}

const p = new Point(); // ✅ — implicit constructor runs
p.x; // 0 ✅
p.y; // 0 ✅

// Subclass — implicit constructor forwards all args to super:
class Point3D extends Point {
  z = 0;
  // Implicit:
  // constructor(...args) { super(...args); }
}

new Point3D(); // ✅ — implicit super() called
```

### Constructor Return Override

```js
class Foo {
  constructor() {
    this.created = true;

    // Return object → replaces 'this':
    return { hijacked: true };     // ← overrides
  }
}

const f = new Foo();
f.created;   // undefined 😱 — 'this' was replaced
f.hijacked;  // true

// Return primitive → ignored, 'this' used:
class Bar {
  constructor() {
    this.created = true;
    return 42;           // ← ignored (primitive)
  }
}
new Bar().created; // true ✅

// Legitimate use — singleton / cache:
class Config {
  static #instance = null;

  constructor(data) {
    if (Config.#instance) return Config.#instance; // return existing ✅
    Object.assign(this, data);
    Config.#instance = this;
  }

  static reset() { Config.#instance = null; }
}

const a = new Config({ debug: true });
const b = new Config({ debug: false }); // returns existing instance
a === b;            // true ✅ — same object
b.debug;            // true ✅ — from first construction
b instanceof Config; // true ✅ — same class returned
```

## 3️⃣ Inheritance Constructor — `super()`

### `super()` Rules

```
┌──────────────────────────────────────────────────────────┐
│              super() RULES — ALL MANDATORY               │
│                                                          │
│  1. MUST call super() in subclass constructor            │
│  2. MUST call before any 'this' access                   │
│  3. MUST call before returning                           │
│  4. Automatically called if no constructor defined       │
│  5. 'this' UNINITIALIZED until super() returns           │
│  6. new.target = outermost class (not parent)            │
└──────────────────────────────────────────────────────────┘
```

```js
class Animal {
  #name;
  #energy = 100;

  constructor(name) {
    this.#name   = name;
    this.species = this.constructor.species ?? "Unknown"; // new.target aware
  }

  get name()   { return this.#name; }
  get energy() { return this.#energy; }

  move(distance) {
    this.#energy -= distance;
    return this;
  }
}

class Dog extends Animal {
  static species = "Canis lupus";
  #breed;
  #tricks = new Set();

  constructor(name, breed) {
    // 'this' NOT available yet:
    // this.#breed = breed; ❌ ReferenceError

    super(name);             // ← triggers Animal constructor
                             // After this: 'this' is available

    // Now safe to use 'this':
    this.#breed = breed;
  }

  learn(trick) { this.#tricks.add(trick); return this; }
  perform(trick) {
    if (!this.#tricks.has(trick)) throw new Error(`Dog doesn't know ${trick}`);
    this.move(2); // inherited method ✅
    return `${this.name} performs ${trick}!`;
  }

  get breed()  { return this.#breed; }
  get tricks() { return [...this.#tricks]; }
}

class GoldenRetriever extends Dog {
  constructor(name) {
    super(name, "Golden Retriever"); // calls Dog → Animal chain
    // All ancestor constructors + fields complete ✅
  }

  fetch(item) {
    this.move(5);
    return `${this.name} fetches the ${item}!`;
  }
}

const dog = new GoldenRetriever("Buddy");
dog.name;     // "Buddy" ✅
dog.breed;    // "Golden Retriever" ✅
dog.species;  // "Canis lupus" ✅ — from Dog.species via new.target
dog.energy;   // 100 ✅

dog.learn("sit").learn("shake");
dog.perform("sit"); // "Buddy performs sit!"
dog.fetch("ball");  // "Buddy fetches the ball!"
```

### `new.target` — Polymorphic and Abstract

```js
// Abstract class guard:
class Shape {
  constructor(color) {
    if (new.target === Shape) {
      throw new TypeError("Shape is abstract — cannot instantiate directly");
    }
    this.color = color;
    // new.target = actual subclass being constructed:
    this.type = new.target.name;
  }

  area()      { throw new Error(`${this.constructor.name}.area() required`); }
  perimeter() { throw new Error(`${this.constructor.name}.perimeter() required`); }
}

class Circle extends Shape {
  #r;
  constructor(r, color = "black") {
    super(color);           // new.target = Circle ✅
    this.#r = r;
  }
  area()      { return Math.PI * this.#r ** 2; }
  perimeter() { return 2 * Math.PI * this.#r; }
}

new Shape("red");    // ❌ TypeError: Shape is abstract
new Circle(5);       // ✅ — new.target = Circle throughout
new Circle(5).type;  // "Circle" ✅ — from new.target.name

// new.target in static — polymorphic factory:
class Model {
  static create(data) {
    return new this(data); // 'this' = calling class
  }

  constructor(data) {
    this.type = new.target.name; // always the outermost class
    Object.assign(this, data);
  }
}

class User extends Model { }
class Product extends Model { }

User.create({ name: "Ali" }).type;     // "User" ✅
Product.create({ name: "Book" }).type; // "Product" ✅
```

## 4️⃣ Constructor Patterns

### Static Factory Method — Replacing Constructor

```js
// Private constructor + static factories:
class Color {
  #r; #g; #b; #a;

  // Private — cannot be called directly:
  constructor(r, g, b, a = 1) {
    this.#r = Math.round(Math.min(255, Math.max(0, r)));
    this.#g = Math.round(Math.min(255, Math.max(0, g)));
    this.#b = Math.round(Math.min(255, Math.max(0, b)));
    this.#a = Math.min(1, Math.max(0, a));
  }

  // Named factories — express INTENT:
  static fromRGB(r, g, b)          { return new Color(r, g, b); }
  static fromRGBA(r, g, b, a)      { return new Color(r, g, b, a); }

  static fromHex(hex) {
    const clean = hex.replace("#", "");
    return new Color(
      parseInt(clean.slice(0, 2), 16),
      parseInt(clean.slice(2, 4), 16),
      parseInt(clean.slice(4, 6), 16)
    );
  }

  static fromHSL(h, s, l) {
    // HSL → RGB conversion (complex math hidden behind clear name)
    const c = (1 - Math.abs(2*l - 1)) * s;
    const x = c * (1 - Math.abs((h / 60) % 2 - 1));
    const m = l - c/2;
    let r, g, b;
    if (h < 60)       [r,g,b] = [c, x, 0];
    else if (h < 120) [r,g,b] = [x, c, 0];
    else if (h < 180) [r,g,b] = [0, c, x];
    else if (h < 240) [r,g,b] = [0, x, c];
    else if (h < 300) [r,g,b] = [x, 0, c];
    else              [r,g,b] = [c, 0, x];
    return new Color((r+m)*255, (g+m)*255, (b+m)*255);
  }

  static named(name) {
    const NAMES = { red: "#FF0000", green: "#00FF00", blue: "#0000FF", white: "#FFFFFF" };
    if (!NAMES[name]) throw new Error(`Unknown color: ${name}`);
    return Color.fromHex(NAMES[name]);
  }

  // Public API:
  toHex()   { return `#${[this.#r, this.#g, this.#b].map(c => c.toString(16).padStart(2, "0")).join("")}`; }
  toRGBA()  { return `rgba(${this.#r},${this.#g},${this.#b},${this.#a})`; }
  mix(other, ratio = 0.5) {
    return new Color(
      this.#r * (1-ratio) + other.#r * ratio,
      this.#g * (1-ratio) + other.#g * ratio,
      this.#b * (1-ratio) + other.#b * ratio,
    );
  }

  [Symbol.toPrimitive](hint) {
    return hint === "number" ? (this.#r << 16 | this.#g << 8 | this.#b) : this.toHex();
  }
}

// Clear intent via named constructors:

const blue   = Color.fromHex("#0000FF");
const gold   = Color.fromHSL(43, 1, 0.5);

`Color: ${red}`;    // "#ff0000"
+red;               // 16711680 (0xFF0000)
```

```js
class DatabasePool {
  #pool;
  #stats = { queries: 0, errors: 0 };

  // Private — not directly callable:
  constructor(pool) {
    this.#pool = pool;
  }

  // The ONLY way to create a DatabasePool:
  static async create({
    host, port = 5432, database, user, password,
    max = 10, idleTimeoutMs = 30000
  }) {
    // Validate:
    if (!host || !database || !user) {
      throw new TypeError("host, database, and user are required");
    }

    // Async setup:
    const { Pool } = await import("pg");
    const pool = new Pool({ host, port, database, user, password, max, idleTimeoutMillis: idleTimeoutMs });

    // Validate connection before returning:
    const client = await pool.connect();
    try {
      await client.query("SELECT 1");
    } finally {
      client.release();
    }

    const instance = new DatabasePool(pool);
    console.log(`✅ DatabasePool connected to ${host}/${database}`);
    return instance;
  }

  async query(sql, params = []) {
    this.#stats.queries++;
    try {
      const { rows } = await this.#pool.query(sql, params);
      return rows;
    } catch (err) {
      this.#stats.errors++;
      throw err;
    }
  }

  async transaction(fn) {
    const client = await this.#pool.connect();
    try {
      await client.query("BEGIN");
      const result = await fn(client);
      await client.query("COMMIT");
      return result;
    } catch (err) {
      await client.query("ROLLBACK");
      throw err;
    } finally {
      client.release();
    }
  }

  get stats()     { return { ...this.#stats }; }
  async end()     { await this.#pool.end(); }
}
```

### Factory Function Pattern — Without `new`

```js
// No class, no new — just a function that returns an object:
function createEventEmitter() {
  // Private state in closure:
  const listeners = new Map();
  let eventCount  = 0;

  // Private helper:
  function getOrCreate(event) {
    if (!listeners.has(event)) listeners.set(event, new Set());
    return listeners.get(event);
  }

  // Public API:
  return Object.freeze({
    on(event, handler) {
      if (typeof handler !== "function") throw new TypeError("handler must be a function");
      getOrCreate(event).add(handler);
      return () => listeners.get(event)?.delete(handler);
    },

    once(event, handler) {
      const wrapper = (...args) => {
        listeners.get(event)?.delete(wrapper);
        return handler(...args);
      };
      wrapper._original = handler;
      return this.on(event, wrapper);
    },

    off(event, handler) {
      const set = listeners.get(event);
      if (!set) return false;
      const direct  = set.delete(handler);
      const wrapped = [...set].find(h => h._original === handler);
      if (wrapped) set.delete(wrapped);
      return direct || !!wrapped;
    },

    emit(event, ...args) {
      eventCount++;
      getOrCreate(event).forEach(h => {
        try { h(...args); } catch (err) { console.error(err); }
      });
    },

    get eventCount() { return eventCount; },
    listenerCount(event) { return listeners.get(event)?.size ?? 0; },
  });
}

const emitter = createEventEmitter(); // no new needed ✅
const off = emitter.on("data", chunk => console.log(chunk));
emitter.emit("data", { id: 1 });
emitter.eventCount; // 1 ✅
emitter.listeners;  // undefined ✅ — truly private
off();              // unsubscribe ✅
```

```js
class Money {
  #amount;
  #currency;
  static #CURRENCIES = new Set(["USD", "EUR", "INR", "GBP", "JPY"]);

  constructor(amount, currency) {
    // Validate in constructor — guarantee invariants:
    if (!Number.isFinite(amount) || amount < 0) {
      throw new RangeError(`Invalid amount: ${amount}`);
    }
    if (!Money.#CURRENCIES.has(currency)) {
      throw new TypeError(`Unsupported currency: ${currency}`);
    }

    // Normalize: store as integer cents to avoid floating point:
    this.#amount   = Math.round(amount * 100);
    this.#currency = currency;

    // Immutable after construction:
    Object.freeze(this);
  }

  get amount()   { return this.#amount / 100; }
  get currency() { return this.#currency; }
  get cents()    { return this.#amount; }

  add(other) {
    if (other.#currency !== this.#currency) {
      throw new TypeError(`Currency mismatch: ${this.#currency} vs ${other.#currency}`);
    }
    return new Money((this.#amount + other.#amount) / 100, this.#currency);
  }

  subtract(other) {
    if (other.#currency !== this.#currency) throw new TypeError("Currency mismatch");
    if (other.#amount > this.#amount) throw new RangeError("Insufficient funds");
    return new Money((this.#amount - other.#amount) / 100, this.#currency);
  }

  multiply(factor) {
    if (!Number.isFinite(factor) || factor < 0) throw new RangeError("Invalid factor");
    return new Money((this.#amount * factor) / 100, this.#currency);
  }

  equals(other) {
    return #amount in other &&
           this.#amount   === other.#amount &&
           this.#currency === other.#currency;
  }

  isGreaterThan(other) { return this.#amount > other.#amount; }

  [Symbol.toPrimitive](hint) {
    return hint === "number" ? this.#amount / 100 : `${this.#currency} ${(this.#amount/100).toFixed(2)}`;
  }

  toJSON() { return { amount: this.#amount / 100, currency: this.#currency }; }
  toString() { return `${[Symbol.toPrimitive]}("string")`; }

  // Named constructors for clarity:
  static usd(amount) { return new Money(amount, "USD"); }
  static eur(amount) { return new Money(amount, "EUR"); }
  static inr(amount) { return new Money(amount, "INR"); }
  static fromJSON({ amount, currency }) { return new Money(amount, currency); }
}
```

### Pattern 2 — Registry Constructor Pattern

```js
// Constructor auto-registers instances:
class EventHandler {
  static #handlers = new Map();

  static get(eventType) {
    return EventHandler.#handlers.get(eventType);
  }

  static getAll() {
    return [...EventHandler.#handlers.entries()];
  }

  #eventType;
  #handler;
  #options;

  constructor(eventType, handler, options = {}) {
    if (typeof eventType !== "string" || !eventType.trim()) {
      throw new TypeError("eventType must be non-empty string");
    }
    if (typeof handler !== "function") {
      throw new TypeError("handler must be a function");
    }
    if (EventHandler.#handlers.has(eventType)) {
      throw new Error(`Handler already registered for: ${eventType}`);
    }

    this.#eventType = eventType;
    this.#handler   = handler;
    this.#options   = { once: false, priority: 0, ...options };

    // Auto-register at construction:
    EventHandler.#handlers.set(eventType, this);
  }

  async invoke(data) {
    try {
      await this.#handler(data);
      if (this.#options.once) {
        EventHandler.#handlers.delete(this.#eventType);
      }
    } catch (err) {
      console.error(`Handler ${this.#eventType} failed:`, err);
      throw err;
    }
  }

  get eventType() { return this.#eventType; }
  get priority()  { return this.#options.priority; }

  destroy() {
    EventHandler.#handlers.delete(this.#eventType);
  }
}
```

### Pattern 3 — Builder via Constructor

```js
// Fluent builder for complex object construction:
class QueryBuilder {
  #table;
  #conditions = [];
  #columns    = ["*"];
  #orderBys   = [];
  #limit      = null;
  #offset     = null;
  #joins      = [];
  #params     = [];
  #paramCount = 0;

  constructor(table) {
    if (!table || typeof table !== "string") {
      throw new TypeError("table name required");
    }
    this.#table = table;
  }

  // Each method returns 'this' for chaining:
  select(...columns)   { this.#columns = columns; return this; }

  where(condition, ...values) {
    values.forEach(v => this.#params.push(v));
    const paramRefs = values.map(() => `$${++this.#paramCount}`);
    let paramIdx = 0;
    const resolved = condition.replace(/\?/g, () => paramRefs[paramIdx++]);
    this.#conditions.push(resolved);
    return this;
  }

  orderBy(column, direction = "ASC") {
    this.#orderBys.push(`${column} ${direction}`);
    return this;
  }

  limit(n)  { this.#limit = n; return this; }
  offset(n) { this.#offset = n; return this; }

  join(table, on, type = "INNER") {
    this.#joins.push(`${type} JOIN ${table} ON ${on}`);
    return this;
  }

  build() {
    const parts = [
      `SELECT ${this.#columns.join(", ")}`,
      `FROM ${this.#table}`,
      ...this.#joins,
      this.#conditions.length ? `WHERE ${this.#conditions.join(" AND ")}` : "",
      this.#orderBys.length   ? `ORDER BY ${this.#orderBys.join(", ")}` : "",
      this.#limit  !== null   ? `LIMIT ${this.#limit}` : "",
      this.#offset !== null   ? `OFFSET ${this.#offset}` : "",
    ].filter(Boolean);

    return { sql: parts.join(" "), params: this.#params };
  }

  async execute(pool) {
    const { sql, params } = this.build();
    const { rows } = await pool.query(sql, params);
    return rows;
  }

  // Static factory for readability:
  static from(table) { return new QueryBuilder(table); }
}

const { sql, params } = QueryBuilder
  .from("users")
  .select("id", "name", "email")
  .join("orders", "users.id = orders.user_id", "LEFT")
  .where("users.active = ?", true)
  .where("users.role = ?", "admin")
  .orderBy("users.created_at", "DESC")
  .limit(20)
  .offset(40)
  .build();

// SELECT id, name, email FROM users
// LEFT JOIN orders ON users.id = orders.user_id
// WHERE users.active = $1 AND users.role = $2
// ORDER BY users.created_at DESC
// LIMIT 20 OFFSET 40
```

## 📊 DSA / Internals Connection

> A constructor is the JS implementation of **object initialization** in the **object construction pattern**. V8 represents each unique constructor-invocation pattern as a **hidden class (Map)** — a shape that describes property layout. The sequence of property assignments in a constructor defines a **transition tree**: each `this.x = val` adds an edge in this tree. All instances of the same class that execute the constructor identically end up at the same leaf node = same hidden class = O(1) property access via shape-indexed lookup.
>
> The `new` operator implements **two-phase construction** from class theory: first **allocation** (object creation + prototype assignment), then **initialization** (constructor body). In derived classes, `super()` delegates allocation to the base class — the derived class only handles initialization. This mirrors the **base-class-first** construction order in C++ and Java, ensuring base invariants are established before derived state is added.
>
> TurboFan **inlines** small constructors at call sites — eliminating function call overhead. A constructor called 10,000+ times with the same shape of arguments gets compiled directly into the calling function's machine code. This is the same **method inlining** optimization used in all modern JIT compilers.
