In JavaScript, some identifiers are reserved to perform special functions.
These reserved identifiers are called **KEYWORDS** or **RESERVED WORDS**.

<Aside type="caution">
You **CANNOT** use them as identifiers (variable/class/function names).
</Aside>

**Why?** Because each keyword already has a fixed meaning in the JavaScript engine.

```javascript
let class = 10; // ❌ Syntax Error
```

## 12. Reserved Literals

🪤 Trap 1 — true, false, null are literals, not normal identifiers

```javascript
true
false
null
undefined
NaN
Infinity
```

Example:

```javascript
let true = 1; // ❌ Syntax Error
```

---

🪤 Trap 2 — Unicode identifiers are valid — obfuscation attack

```javascript
// Looks like "false" — IS NOT false
// Cyrillic 'а' instead of ASCII 'a'

let fаlse = 10;

console.log(fаlse);
```

Compiler/engine accepts it — human eye may miss it.

Used in:
- obfuscated code
- phishing-style attacks
- malicious scripts

## 13. Operators vs Keywords

| Category | Example |
|---|---|
| Keyword | `class`, `return`, `function` |
| Identifier | `userAge`, `BankAccount` |
| Literal | `10`, `"hello"`, `true` |
| Operator | `+`, `===`, `&&` |

Example:

```javascript
const age = 10;
```

| Token | Category |
|---|---|
| `const` | keyword |
| `age` | identifier |
| `10` | literal |

---

## 14. Important Notes ⚠️

### JavaScript is case-sensitive

```javascript
let Age = 10;
let age = 20;
```

These are different identifiers.

---

### Keywords cannot be identifiers

```javascript
let return = 5; // ❌ Syntax Error
```

---

### `$` and `_` are valid identifier characters

```javascript
let $price = 100;
let _hidden = true;
```

✅ valid identifiers.
