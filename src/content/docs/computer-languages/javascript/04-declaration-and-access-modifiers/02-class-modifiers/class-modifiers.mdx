## 🏛️ Class Modifiers in JavaScript

> Java has strict keywords (`public`, `final`, `abstract`).  
> **JavaScript has none of these for classes.**  
> Instead, JS relies on **conventions**, **symbols**, and **runtime checks** to achieve similar goals.

<Aside type="tip">
**🧠 Mental Model**:  
In Java, the compiler enforces rules.  
In JS, **you** enforce rules via code structure and conventions.  
✅ **Key Difference**: Everything is `public` by default unless you use specific tricks (like `#` or Modules).
</Aside>

---

## 🗂️ Access Control (Visibility)

### 1. Module Scope (The New "Package-Private")

In modern JS (ES Modules), anything not exported is **private to the file**. This replaces Java's "default/package-private" visibility.

<Code lang="js" title="Module Privacy" code={`
// internalUtils.js
// Not exported → Private to this module
class Helper {
    doWork() { console.log("Internal"); }
}

// Exported → Public API
export class PublicService {
    constructor() {
        this.helper = new Helper(); // Can use internal class
    }
}
`} />

### 2. Private Fields (`#`)

JS uses `#` for true private fields. These cannot be accessed outside the class.

<Code lang="js" title="Private Fields" code={`
class BankAccount {
    #balance = 0; // 🔒 Truly private

    deposit(amount) {
        this.#balance += amount;
    }

    getBalance() {
        return this.#balance;
    }
}

const acc = new BankAccount();
// console.log(acc.#balance); // 💥 SyntaxError
`} />

### 3. Convention (`_`)

Using an underscore `_` signals "protected" or "internal". It’s not enforced, but devs respect it.

<Code lang="js" title="Protected Convention" code={`
class BaseComponent {
    _render() {
        console.log("Rendering...");
    }
}

class Button extends BaseComponent {
    click() {
        this._render(); // ✅ Accepted convention for "protected"
    }
}
`} />

## 🔒 Emulating `final` Classes

Java’s `final` prevents inheritance. JS has no keyword for this, but we can prevent it at runtime.

<Code lang="js" title="Preventing Extension" code={`
class FinalClass {
    constructor() {
        // Check if 'this' is exactly FinalClass, not a subclass
        if (new.target !== FinalClass) {
            throw new TypeError("Cannot extend FinalClass");
        }
    }
}

class Child extends FinalClass {
    // 💥 TypeError: Cannot extend FinalClass
}
`} />

<Aside type="note">
**Why?** JS is dynamic. Preventing inheritance is rarely needed because JS doesn't rely on rigid hierarchies for security like Java does. Composition is preferred.
</Aside>

## 🎭 Emulating `abstract` Classes

Java’s `abstract` prevents instantiation and forces method implementation. In JS, we throw errors manually.

<Code lang="js" title="Abstract Base Class" code={`
class Shape {
    constructor() {
        // Prevent direct instantiation
        if (new.target === Shape) {
            throw new TypeError("Cannot construct Shape directly");
        }
    }

    // Abstract method
    area() {
        throw new Error("Method 'area()' must be implemented.");
    }
}

class Circle extends Shape {
    constructor(radius) {
        super(); // ✅ Calls parent constructor (checks new.target)
        this.radius = radius;
    }

    area() {
        return Math.PI * this.radius ** 2; // ✅ Implementation provided
    }
}

// const s = new Shape(); // 💥 TypeError
const c = new Circle(5); // ✅ Works
console.log(c.area());   // 78.53...
`} />

## 🆚 Java vs JS Class Modifiers

| Java Concept | JavaScript Equivalent | How it Works |
|-------------|----------------------|--------------|
| **`public`** | Default / `export` | Everything is public unless hidden by module scope. |
| **`private`** | `#field` | Hard privacy enforced by engine. |
| **`protected`** | `_method` (Convention) | Soft privacy. Devs agree not to touch it. |
| **`final` Class** | `new.target` Check | Runtime check in constructor. |
| **`abstract` Class** | Throw Error in Constructor | Manual enforcement. |
| **`static`** | `static` keyword | Same syntax, same behavior. |
| **`interface`** | ❌ None (Use TS) | JS uses Duck Typing. |

## 🎯 Interview Cheat Sheet

<CardGrid>
  <Card title="Q: How do you make a class private in JS?" icon="information">
    You don't make the *class* private, but you can hide it using **ES Modules**. If you don't `export` it, it's only accessible within that file.
  </Card>
  
  <Card title="Q: How do you prevent a class from being extended?" icon="approve-check">
    Check `new.target` in the constructor. If it doesn't match the class name, throw an error.
  </Card>

  <Card title="Q: Does JS have abstract classes?" icon="error">
    No. You simulate them by throwing an error in the constructor if `new.target` is the base class, and throwing errors in unimplemented methods.
  </Card>

  <Card title="Q: What is the difference between `#` and `_`?" icon="rocket">
    `#` is **hard privacy** (syntax error if accessed outside). `_` is **soft privacy** (convention only, still accessible).
  </Card>
</CardGrid>

## 1️⃣ Public Fields and Methods — Default

### Public Fields

```js
class User {
  // Public field declarations (ES2022):
  name = "anonymous";    // initialized per instance
  age  = 0;
  role = "user";         // default value

  // No initializer — undefined by default:
  email;                 // public, undefined

  constructor(name, age) {
    this.name = name;    // overrides field initializer
    this.age  = age;
  }
}

const u = new User("Ali", 20);
u.name  // "Ali"   — constructor overwrote initializer
u.role  // "user"  — from field declaration
u.email // undefined

// Public fields are OWN properties — not on prototype:
u.hasOwnProperty("name")  // true ✅
u.hasOwnProperty("role")  // true ✅
```

### Public Methods

```js
class Calculator {
  // Method — lives on Calculator.prototype (SHARED):
  add(a, b) { return a + b; }

  // vs Field function — lives on instance (NOT shared):
  multiply = (a, b) => a * b;  // arrow — own property per instance

  // Both callable the same way:
  // calc.add(1,2) and calc.multiply(1,2)
}

const c1 = new Calculator();
const c2 = new Calculator();

// Method — same reference:
c1.add === c2.add                   // true ✅ — shared on prototype

// Field function — different reference:
c1.multiply === c2.multiply         // false — each instance gets own copy
```

```
┌──────────────────────────────────────────────────────────┐
│        METHOD vs FIELD FUNCTION — MEMORY                 │
│                                                          │
│  method() {}          → Prototype (ONE copy, shared)     │
│  method = () => {}    → Instance (N copies, one each)    │
│                                                          │
│  1000 instances:                                         │
│  method()       → 1 function in memory                   │
│  method = ()=>  → 1000 functions in memory 😱            │
│                                                          │
│  Use field functions ONLY when you need:                 │
│  → guaranteed 'this' binding (event handlers)            │
│  → pass method as callback without .bind()               │
└──────────────────────────────────────────────────────────┘
```

```js
// Real use — event handler that needs correct 'this':
class Button {
  label = "Click me";

  // Field function — 'this' always bound to instance:
  handleClick = () => {
    console.log(this.label); // ✅ always works
  };

  // Method — 'this' depends on call context:
  handleClickMethod() {
    console.log(this.label); // 😱 this = undefined when detached
  }
}

const btn = new Button();
document.addEventListener("click", btn.handleClick);       // ✅
document.addEventListener("click", btn.handleClickMethod); // 😱
```

## 2️⃣ `#` Private Fields and Methods — True Privacy

### Private Fields

```js
class BankAccount {
  #balance = 0;          // private — TRULY inaccessible outside
  #owner;                // private — no initializer

  constructor(owner, initialBalance) {
    this.#owner   = owner;
    this.#balance = initialBalance;
  }

  deposit(amount) {
    if (amount <= 0) throw new RangeError("Amount must be positive");
    this.#balance += amount;
  }

  withdraw(amount) {
    if (amount > this.#balance) throw new Error("Insufficient funds");
    this.#balance -= amount;
  }

  getBalance() {
    return this.#balance; // ✅ inside class — accessible
  }
}

const acc = new BankAccount("Ali", 1000);
acc.#balance;         // ❌ SyntaxError — truly private
acc["#balance"];      // undefined — not the same property
acc.getBalance();     // 1000 ✅
```

### How Private Fields Work Internally

```
┌──────────────────────────────────────────────────────────┐
│         PRIVATE FIELD INTERNALS (V8)                     │
│                                                          │
│  Private fields use [[PrivateName]] internal slots       │
│  Not in the object's property map (hidden class)         │
│  Cannot be found via:                                    │
│    - obj.#name (outside class → SyntaxError at PARSE)   │
│    - Object.keys()                                       │
│    - for...in                                            │
│    - JSON.stringify()                                    │
│    - Proxy get trap                                      │
│    - Object.getOwnPropertyNames()                        │
│    - Reflect.ownKeys()                                   │
│                                                          │
│  Storage: each class has a unique "brand"                │
│  Private slot = (brand, name) → value                    │
│  Brand check happens at access time                      │
│  → Different class with same #name = different brand     │
│  → Cross-class access impossible by design               │
└──────────────────────────────────────────────────────────┘
```

```js
// Private vs "pseudo-private" with underscore:
class Old {
  _secret = 42;     // "private" by convention — still public
}

class New {
  #secret = 42;     // actually private — enforced by engine
}

const old = new Old();
old._secret;         // 42 😱 — accessible, convention only
old["_secret"];      // 42 😱 — accessible

const neo = new New();
neo.#secret;         // ❌ SyntaxError — parse-time error
neo["#secret"];      // undefined — different key
Object.keys(neo);    // [] — private not enumerable
```

### Private Methods

```js
class Validator {
  #rules = [];

  // Private method — only callable inside class:
  #validate(value, rule) {
    if (!rule.test(value)) {
      throw new Error(`Validation failed: ${rule.message}`);
    }
  }

  // Private static method:
  static #sanitize(input) {
    return String(input).trim().toLowerCase();
  }

  // Public method uses private method:
  addRule(rule) {
    this.#rules.push(rule);
    return this; // chaining
  }

  check(value) {
    const clean = Validator.#sanitize(value);
    this.#rules.forEach(rule => this.#validate(clean, rule));
    return true;
  }
}

const v = new Validator();
v.#validate("x", {});   // ❌ SyntaxError
v.check("HELLO");        // ✅ calls #validate internally
```

### `in` Operator — Brand Check

```js
// Check if object has private field (ES2022):
class Circle {
  #radius;
  constructor(r) { this.#radius = r; }

  static isCircle(obj) {
    return #radius in obj; // ✅ brand check — true if obj has #radius
  }
}

const c = new Circle(5);
Circle.isCircle(c);       // true  ✅
Circle.isCircle({});      // false ✅

// Real use — safe duck typing with private fields:
class Queue {
  #items = [];

  static isQueue(obj) {
    return #items in obj; // more reliable than instanceof
  }
}
// Works even across realms (unlike instanceof)
```

## 3️⃣ `static` — Class-Level Members

### Static Fields

```js
class Config {
  // Static field — belongs to CLASS not instances:
  static MAX_RETRY    = 3;
  static DEFAULT_PORT = 8080;
  static #instances   = 0;      // static private

  constructor() {
    Config.#instances++;
  }

  static getInstanceCount() {
    return Config.#instances;
  }
}

Config.MAX_RETRY;      // 3  ✅ — on class
Config.DEFAULT_PORT;   // 8080

const c = new Config();
c.MAX_RETRY;           // undefined 😱 — not on instance
c.constructor.MAX_RETRY; // 3 ✅ — via constructor
```

### Static Methods

```js
class MathUtils {
  // Static method — called on class, not instance:
  static add(a, b)      { return a + b; }
  static subtract(a, b) { return a - b; }
  static clamp(n, min, max) {
    return Math.min(Math.max(n, min), max);
  }

  // Factory method — common static pattern:
  static fromArray([a, b]) {
    return new MathUtils(a, b); // creates instance from static
  }
}

MathUtils.add(1, 2);     // 3  ✅
const m = new MathUtils();
m.add(1, 2);             // ❌ TypeError: m.add is not a function
```

### Static Initialization Blocks (ES2022)

```js
// Run arbitrary code during class definition:
class DatabasePool {
  static #pool;
  static #config;
  static #initialized = false;

  // Static block — runs ONCE when class is defined:
  static {
    DatabasePool.#config = {
      host: process.env.DB_HOST || "localhost",
      port: parseInt(process.env.DB_PORT, 10) || 5432,
      max:  parseInt(process.env.DB_MAX_CONN, 10) || 10,
    };

    // Complex initialization logic:
    if (process.env.NODE_ENV !== "test") {
      DatabasePool.#pool = DatabasePool.#createPool();
      DatabasePool.#initialized = true;
    }

    console.log("DatabasePool class initialized");
  }

  static #createPool() {
    // create connection pool
    return { connections: [] };
  }

  static getPool() {
    if (!DatabasePool.#initialized) {
      throw new Error("Pool not initialized — run in non-test env");
    }
    return DatabasePool.#pool;
  }
}
```

```
┌──────────────────────────────────────────────────────────┐
│         STATIC BLOCK EXECUTION ORDER                     │
│                                                          │
│  class A {                                               │
│    static x = 1;              // evaluated first         │
│    static { console.log(A.x); } // runs second          │
│    static y = A.x + 1;        // evaluated third        │
│    static { console.log(A.y); } // runs fourth          │
│  }                                                       │
│                                                          │
│  → 1                                                     │
│  → 2                                                     │
│                                                          │
│  Static fields and blocks run TOP TO BOTTOM             │
│  In declaration order — like top-level module code       │
└──────────────────────────────────────────────────────────┘
```

### Static Inheritance

```js
class Animal {
  static kingdom = "Animalia";
  static describe() { return `Kingdom: ${this.kingdom}`; }
}

class Dog extends Animal {
  static species = "Canis lupus";
}

// Static members ARE inherited:
Dog.kingdom;        // "Animalia" ✅ — inherited from Animal
Dog.describe();     // "Kingdom: Animalia" ✅

// 'this' in inherited static — refers to CALLED class:
class Cat extends Animal {
  static kingdom = "Felidae"; // override
}

Cat.describe();     // "Kingdom: Felidae" — this = Cat ✅
Animal.describe();  // "Kingdom: Animalia" — this = Animal ✅
```

## 4️⃣ `get` / `set` — Accessors

### Getters

```js
class Rectangle {
  #width;
  #height;

  constructor(w, h) {
    this.#width  = w;
    this.#height = h;
  }

  // Getter — accessed like property, computed on access:
  get area()      { return this.#width * this.#height; }
  get perimeter() { return 2 * (this.#width + this.#height); }
  get diagonal()  {
    return Math.sqrt(this.#width ** 2 + this.#height ** 2);
  }

  // Getter for serialization:
  get dimensions() {
    return { width: this.#width, height: this.#height };
  }
}

const rect = new Rectangle(5, 3);
rect.area;            // 15 — no ()  ← looks like property
rect.perimeter;       // 16
rect.area = 100;      // silently fails (no setter) in sloppy
                      // ❌ TypeError in strict mode
```

### Setters

```js
class Temperature {
  #celsius = 0;

  get celsius()    { return this.#celsius; }
  get fahrenheit() { return this.#celsius * 9/5 + 32; }
  get kelvin()     { return this.#celsius + 273.15; }

  // Setter — validate and transform on write:
  set celsius(value) {
    if (typeof value !== "number") {
      throw new TypeError("Temperature must be a number");
    }
    if (value < -273.15) {
      throw new RangeError("Below absolute zero");
    }
    this.#celsius = value;
  }

  // Setter from other unit:
  set fahrenheit(value) {
    this.celsius = (value - 32) * 5/9;  // reuses celsius setter validation
  }

  set kelvin(value) {
    this.celsius = value - 273.15;
  }
}

const temp = new Temperature();
temp.celsius    = 100;  // ✅ uses setter — validates
temp.fahrenheit;        // 212 — computed from #celsius
temp.fahrenheit = 32;   // ✅ sets via fahrenheit setter
temp.celsius;           // 0 — correct conversion
temp.celsius = -300;    // ❌ RangeError — caught by setter
```

### Getter Without Setter — Computed Read-Only

```js
class Circle {
  constructor(radius) {
    this.radius = radius;
  }

  get area()          { return Math.PI * this.radius ** 2; }
  get circumference() { return 2 * Math.PI * this.radius; }

  // Getter + no setter = effectively read-only:
  get id() {
    return `circle-${this.radius.toFixed(2)}`;
  }
}

const c = new Circle(5);
c.area;       // 78.53... — computed
c.area = 100; // silently fails (sloppy) or TypeError (strict)
```

### Static Getters / Setters

```js
class AppConfig {
  static #env = "development";

  static get env()        { return AppConfig.#env; }
  static get isDev()      { return AppConfig.#env === "development"; }
  static get isProd()     { return AppConfig.#env === "production"; }

  static set env(value) {
    const valid = ["development", "staging", "production"];
    if (!valid.includes(value)) {
      throw new Error(`Invalid env: ${value}`);
    }
    AppConfig.#env = value;
  }
}

AppConfig.env;         // "development"
AppConfig.env = "production"; // ✅ uses setter
AppConfig.isProd;      // true ✅
AppConfig.env = "prod"; // ❌ Error: Invalid env
```

## 5️⃣ Abstract Class Pattern — No Keyword, Runtime Enforcement

```js
// JS has NO 'abstract' keyword — enforce at runtime:

class AbstractShape {
  constructor() {
    // Prevent direct instantiation:
    if (new.target === AbstractShape) {
      throw new TypeError(
        "Cannot instantiate abstract class AbstractShape"
      );
    }
  }

  // Abstract method — must be overridden:
  area() {
    throw new Error(
      `${this.constructor.name} must implement area()`
    );
  }

  perimeter() {
    throw new Error(
      `${this.constructor.name} must implement perimeter()`
    );
  }

  // Concrete method — shared by all subclasses:
  describe() {
    return `${this.constructor.name}: area=${this.area().toFixed(2)}`;
  }
}

class Circle extends AbstractShape {
  #radius;
  constructor(r) { super(); this.#radius = r; }

  area()      { return Math.PI * this.#radius ** 2; }  // ✅ implemented
  perimeter() { return 2 * Math.PI * this.#radius; }   // ✅ implemented
}

class Square extends AbstractShape {
  #side;
  constructor(s) { super(); this.#side = s; }

  area()      { return this.#side ** 2; }  // ✅
  perimeter() { return 4 * this.#side; }   // ✅
  // describe() inherited from AbstractShape ✅
}

new AbstractShape(); // ❌ TypeError: Cannot instantiate abstract class
new Circle(5);       // ✅
new Square(4);       // ✅

const c = new Circle(5);
c.describe();        // "Circle: area=78.54" ✅
```

### `new.target` — How Abstract Check Works

```
┌──────────────────────────────────────────────────────────┐
│              new.target INTERNALS                        │
│                                                          │
│  new.target = the constructor that was directly called  │
│               with 'new'                                 │
│                                                          │
│  new AbstractShape()                                     │
│    → new.target = AbstractShape                          │
│    → check: new.target === AbstractShape → throw ✅      │
│                                                          │
│  new Circle(5)                                           │
│    → calls super() inside Circle constructor            │
│    → new.target = Circle (NOT AbstractShape)            │
│    → check: new.target === AbstractShape → false         │
│    → no throw ✅                                         │
│                                                          │
│  new.target is undefined in regular function calls      │
│  new.target is set in constructor calls                 │
└──────────────────────────────────────────────────────────┘
```

```js
// new.target also useful for factory methods:
class Base {
  static create(...args) {
    // new.target here would be Base if called directly
    // Forces use of factory:
    return new this(...args); // 'this' = the class called on
  }
}

class Child extends Base {
  constructor(x) { super(); this.x = x; }
}

Child.create(42);  // ✅ new Child(42)
Base.create(42);   // new Base(42) — no abstract check here
```

## 7️⃣ `extends` and `super` — Inheritance Modifiers

### `extends` Chain

```js
class Animal {
  #name;
  #sound;

  constructor(name, sound) {
    this.#name  = name;
    this.#sound = sound;
  }

  speak() {
    return `${this.#name} says ${this.#sound}`;
  }

  get name() { return this.#name; }
}

class Dog extends Animal {
  #breed;

  constructor(name, breed) {
    super(name, "Woof");  // MUST call super() before using 'this'
    this.#breed = breed;
  }

  fetch() {
    return `${this.name} fetches the ball!`; // uses parent getter
  }

  // Override parent method:
  speak() {
    return super.speak() + "!"; // call parent + extend
  }

  get breed() { return this.#breed; }
}

class GoldenRetriever extends Dog {
  constructor(name) {
    super(name, "Golden Retriever");
  }

  // speak() inherited from Dog → from Animal → extended
}

const dog = new GoldenRetriever("Buddy");
dog.speak();  // "Buddy says Woof!" — Dog.speak → super.speak + "!"
dog.fetch();  // "Buddy fetches the ball!"
dog.breed;    // "Golden Retriever"
```

### `super` — Three Forms

```
┌──────────────────────────────────────────────────────────┐
│              super — THREE USES                          │
│                                                          │
│  1. super() — call parent constructor                    │
│     Must be first in subclass constructor               │
│     Must be called before accessing 'this'              │
│                                                          │
│  2. super.method() — call parent prototype method       │
│     Calls parent's version even if overridden           │
│                                                          │
│  3. super.prop — access parent property                  │
│     (rare — usually used for getters)                   │
└──────────────────────────────────────────────────────────┘
```

```js
class Logger {
```

## 🏭 Real Production Patterns

### Pattern 1 — Repository Pattern with Private State

```js
class UserRepository {
  #db;
  #cache = new Map();
  static #instance = null;

  // Singleton via static:
  static getInstance(db) {
    UserRepository.#instance ??= new UserRepository(db);
    return UserRepository.#instance;
  }

  constructor(db) {
    if (UserRepository.#instance) {
      throw new Error("Use UserRepository.getInstance()");
    }
    this.#db = db;
  }

  // Private helper:
  #buildCacheKey(id) { return `user:${id}`; }

  async findById(id) {
    const key = this.#buildCacheKey(id);

    if (this.#cache.has(key)) {
      return this.#cache.get(key); // cache hit
    }

    const user = await this.#db.query(
      "SELECT * FROM users WHERE id = $1", [id]
    );

    if (user) this.#cache.set(key, user);
    return user;
  }

  async save(user) {
    const saved = await this.#db.query(
      "INSERT INTO users (name, email) VALUES ($1, $2) RETURNING *",
      [user.name, user.email]
    );
    const key = this.#buildCacheKey(saved.id);
    this.#cache.set(key, saved);
    return saved;
  }

  invalidateCache(id) {
    this.#cache.delete(this.#buildCacheKey(id));
  }

  // Static utility:
  static validate(user) {
    if (!user?.name?.trim())        throw new Error("Name required");
    if (!user?.email?.includes("@")) throw new Error("Invalid email");
    return true;
  }
}
```

### Pattern 2 — Observable with Private Internals

```js
class Observable {
  #subscribers = new Map();
  #value;

  constructor(initialValue) {
    this.#value = initialValue;
  }

  get value() { return this.#value; }

  set value(newVal) {
    const oldVal = this.#value;
    this.#value  = newVal;
    if (oldVal !== newVal) {
      this.#notify("change", { oldVal, newVal });
    }
  }

  // Private notification:
  #notify(event, data) {
    const handlers = this.#subscribers.get(event) ?? [];
    handlers.forEach(handler => {
      try { handler(data); }
      catch (err) { console.error("Handler error:", err); }
    });
  }

  subscribe(event, handler) {
    if (!this.#subscribers.has(event)) {
      this.#subscribers.set(event, []);
    }
    this.#subscribers.get(event).push(handler);

    // Return unsubscribe function:
    return () => {
      const handlers = this.#subscribers.get(event);
      const idx = handlers.indexOf(handler);
      if (idx !== -1) handlers.splice(idx, 1);
    };
  }

  static from(value) {
    return new Observable(value);
  }
}

const count = Observable.from(0);
const unsub = count.subscribe("change", ({ oldVal, newVal }) => {
  console.log(`${oldVal} → ${newVal}`);
});

count.value = 1;  // logs: "0 → 1"
count.value = 2;  // logs: "1 → 2"
unsub();          // remove listener
count.value = 3;  // no log
```

### Pattern 3 — Abstract Base with Template Method Pattern

```js
class DataExporter {
  // Template method — defines algorithm skeleton:
  async export(data, destination) {
    this.#validate(data);
    const transformed = await this.transform(data); // abstract
    const formatted   = this.format(transformed);   // abstract
    await this.write(formatted, destination);        // abstract
    return this.#buildReport(data, destination);
  }

  // Private concrete steps:
  #validate(data) {
    if (!Array.isArray(data)) throw new TypeError("Data must be array");
    if (data.length === 0)    throw new Error("Data is empty");
  }

  #buildReport(data, dest) {
    return { count: data.length, destination: dest, timestamp: Date.now() };
  }

  // Abstract methods — subclasses must implement:
  transform(data) {
    throw new Error(`${this.constructor.name}.transform() not implemented`);
  }

  format(data) {
    throw new Error(`${this.constructor.name}.format() not implemented`);
  }

  async write(data, destination) {
    throw new Error(`${this.constructor.name}.write() not implemented`);
  }
}

class CSVExporter extends DataExporter {
  transform(data) {
    return data.map(row =>
      Object.values(row).map(String)
    );
  }

  format(rows) {
    const header = Object.keys(rows[0] ?? {}).join(",");
    return [header, ...rows.map(r => r.join(","))].join("\n");
  }

  async write(content, path) {
    await fs.writeFile(path, content, "utf8");
  }
}

class JSONExporter extends DataExporter {
  transform(data) { return data; }
  format(data)    { return JSON.stringify(data, null, 2); }
  async write(content, path) {
    await fs.writeFile(path, content, "utf8");
  }
}
```

### Trap 2: `super()` must be called before `this` in constructor

## 📊 Complete Modifier Reference Table

| Modifier | Syntax | Accessible From | On Prototype? | Inherited? |
|---|---|---|---|---|
| Public field | `x = 1` | Anywhere | ❌ (own) | ✅ via prototype |
| Public method | `fn() {}` | Anywhere | ✅ | ✅ |
| Private field | `#x = 1` | Class only | ❌ (own) | ❌ |
| Private method | `#fn() {}` | Class only | ✅ (private) | ❌ |
| Static field | `static x` | Via class | ❌ (on class) | ✅ subclasses |
| Static method | `static fn()` | Via class | ❌ (on class) | ✅ subclasses |
| Static private | `static #x` | Class only | ❌ | ❌ |
| Getter | `get x()` | Anywhere | ✅ | ✅ |
| Setter | `set x(v)` | Anywhere | ✅ | ✅ |
| Static getter | `static get x()` | Via class | ❌ (on class) | ✅ |

## 📊 DSA / Internals Connection

> Private fields (`#`) are implemented as **WeakMap-like hidden slots** in V8 — each class has a unique brand symbol, and private fields are stored in a separate map keyed by `(brand, fieldName)`. This is exactly the **WeakMap pattern** that developers used before native private fields existed — `const _private = new WeakMap(); _private.set(this, { balance: 0 })`. The engine now does this automatically, faster, and with parse-time access control.
>
> Static members are properties on the **constructor function object** itself — same mechanism as any JS object property. The inheritance chain for statics is `Child.__proto__ === Parent` — a separate prototype chain for the constructor objects themselves, parallel to the instance prototype chain. Two prototype chains exist simultaneously: one for instances (`Child.prototype → Parent.prototype → Object.prototype`) and one for static members (`Child → Parent → Function.prototype → Object.prototype`).
